# CashOps Agent

CashOps Agent is an AI-powered cash-flow assistant for small businesses.

It uses NVIDIA Nemotron on Nebius to turn invoices and payment notices into structured cash-flow data and forecast 30/60/90-day cash risk.

## Current prototype

The prototype will:

- Read synthetic invoices and payment notices
- Extract amount, due date, counterparty, transaction type, and status
- Flag missing or unclear information
- Convert documents into structured cash-flow events
- Generate 30/60/90-day cash-flow forecasts

## Technology

- Nebius
- NVIDIA Nemotron
- AI agent workflow
- Synthetic financial data only
